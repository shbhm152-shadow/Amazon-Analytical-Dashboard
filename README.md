# 📊 Amazon Analytical Dashboard

## 📌 Project Overview

This project is an **interactive Amazon Prime Video analytical dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes Amazon Prime Video's content catalog and presents key insights related to **Movies, TV Shows, genres, ratings, release years, and other content characteristics**.

The objective of this project is to transform raw data into an interactive and easy-to-understand dashboard that can support **data-driven analysis and decision-making**.

---

## 🎯 Project Objectives

- Analyze the distribution of Movies and TV Shows.
- Understand content trends over the years.
- Analyze genres and content categories.
- Explore content ratings and certifications.
- Identify patterns in the Amazon Prime Video catalog.
- Build an interactive dashboard using Power BI.
- Present analytical findings through clear and effective visualizations.

## 🔍 Analysis Performed

### 🎬 Content Type Analysis

The dashboard compares the distribution of:

- Movies
- TV Shows

This helps understand the overall composition of the Amazon Prime Video catalog.

### 📅 Release Year Analysis

The dashboard examines how the number of titles has changed across different release years, helping identify trends in content production and availability.

### 🎭 Genre Analysis

The project analyzes the distribution of different genres to identify the types of content that are most represented in the catalog.

### ⭐ Rating Analysis

Content ratings are analyzed to understand the target audience and classification of titles available on the platform.

### 🌎 Content Analysis

The dashboard also provides insights into the characteristics and distribution of Amazon Prime Video content across different dimensions.

---

## 📈 Key Insights

Some of the major findings from the analysis include:

- **Movies represent the majority of the catalog**, compared with TV Shows.
- The Amazon Prime Video catalog contains a wide variety of genres and content categories.
- Content availability has changed significantly across different release years.
- The catalog contains content targeted toward different audience age groups.
- Interactive Power BI visualizations make it easier to explore these patterns and compare different segments of the dataset.
